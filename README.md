# バンドマン持ち物リスト

スタジオ・ライブ・レコーディングのシーンごと、担当パートごとに、持ち物チェックリストを管理できるWebアプリです。

**公開URL：** https://sunatrux.github.io/band-mochimono/

## 特徴

- スタジオ／ライブ／レコーディングを個別に登録し、それぞれ独立した持ち物リストを持てる
- 担当パート（ギター、ベース、ドラム、ボーカル、キーボード、ハープ、カホン、サックスなど、追加・並び替え可能）を選ぶと、パートに応じた持ち物リストが自動で組まれる
- 持ち物ごとに「持ってく／レンタル」を設定可能。レンタルはチェックリスト上でグレー表示になり、チェック不要・進捗カウント対象外に
- 「持ってく／レンタル」はイベント単位でも個別に上書き可能（同じ持ち物でも会場によって変えられる）
- CSV出力・取り込みに対応。持ち物リストを他の人と共有したり、配布されたリストを取り込んだりできる
- ログイン不要、アカウント登録不要。ブラウザだけで完結
- iPhoneの「ホーム画面に追加」で、アプリのように使える

## 使い方

1. 上記URLをブラウザで開く
2. 「スタジオ」「ライブ」「録音」タブから、行くイベントを登録
3. 「設定」タブで持ち物やパートを自由にカスタマイズ

## データについて

このアプリはサーバーを持たず、データはすべて**あなたの端末のブラウザ内（localStorage）**に保存されます。他の人や他の端末とはデータは共有されません。複製・改造しても、元のサイトのデータには一切影響しません。
