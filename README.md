# バンドマン持ち物リスト

スタジオ・イベント（ライブ・セッション・集まりなど）・レコーディングのシーンごと、担当パートごとに、持ち物チェックリストを管理できるWebアプリです。

**公開URL：** https://sunatrux.github.io/band-mochimono/

## 特徴

- スタジオ／イベント／レコーディングを個別に登録し、それぞれ独立した持ち物リストを持てる
- 担当パート（ギター、ベース、ドラム、ボーカル、キーボード、カホン、サックスなど、追加・並び替え可能）を選ぶと、パートに応じた持ち物リストが自動で組まれる
- 持ち物ごとに「持ってく／レンタル」を設定可能。レンタルはチェックリスト上でグレー表示になり、チェック不要・進捗カウント対象外に
- 「持ってく／レンタル」はイベント単位でも個別に上書き可能（同じ持ち物でも会場によって変えられる）
- イベントごとに、目立たせたい持ち物を📌ピン留めして先頭に表示（右スワイプ）
- CSV出力・取り込みに対応。持ち物リストを他の人と共有したり、配布されたリストを取り込んだりできる
- ログイン不要、アカウント登録不要。ブラウザだけで完結
- iPhoneの「ホーム画面に追加」で、アプリのように使える
- 一度開けば、電波の弱いスタジオやライブハウスでもオフラインで起動できる

## 使い方

1. 上記URLをブラウザで開く
2. 「スタジオ」「イベント」「レコ」タブから、行く予定を登録
3. 「設定」タブで持ち物やパートを自由にカスタマイズ

## データについて

このアプリはサーバーを持たず、データはすべて**あなたの端末のブラウザ内（localStorage）**に保存されます。他の人や他の端末とはデータは共有されません。ブラウザのデータ消去や機種変更に備えて、「設定」→「データ管理」の**バックアップ**で全データをファイルに保存し、**復元**で戻せます。複製・改造しても、元のサイトのデータには一切影響しません。
